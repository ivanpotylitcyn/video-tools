# Устройство расшифровки

Команды и требования — в [README](README.md).

## Конвейер

`transcribe` — Bash 3.2, `postprocess.py` — Python без сторонних пакетов.

1. Рекурсивно найти видео mp4/mov/m4v/mkv/mts/mxf/avi независимо от регистра.
   Скрытые папки и служебные `._*` пропустить.
2. Составить очередь и план. С `-n` остановиться до создания результатов.
3. Извлечь звук: `ffmpeg -map 0:a:0 -vn -ar 16000 -ac 1 -c:a pcm_s16le`.
   Результат — `audio/<имя>.wav`. Существующий WAV переиспользовать только при
   16 кГц и одном канале; при другом формате пропустить клип с ошибкой.
4. Вызвать `whisper-cli` с VAD, `--carry-initial-prompt`, `-pp` и `-ojf`.
   JSON сначала записать во временную папку. stderr сохранить в лог и пропустить
   через индикатор прогресса. `-np` не применять: нужны строки `vad_segment_info`.
5. Выполнить `postprocess.py vad`, перенести JSON в `json/`, затем через `render`
   собрать `txt/` и `srt/` с заменами и нарезкой субтитров.
6. После каждого клипа показать готовые и оставшиеся клипы/минуты и оценку времени.

Клипы без звука пропускать. Для завершённых клипов достаточно непустого JSON;
TXT/SRT могут быть пустыми при отсутствии речи. `-f` запускает распознавание заново.
При обычном повторном запуске `render --check` определяет необходимость пересборки
по спискам замен, без вызова Whisper.

## Шкала времени и VAD

Используется Silero v6.2.0 с настройками по умолчанию. Границы речи записываются
в JSON как `speech`, в миллисекундах исходного клипа.

В whisper-cli 1.9.5 сегменты уже находятся в шкале исходника, а токены — в шкале
склеенной речи. `fix_vad` пересчитывает токены по строкам `vad_segment_info` из лога,
повторяя алгоритм библиотеки. В логе границы заданы целыми сотыми секунды.

**При обновлении whisper.cpp проверить, требуется ли пересчёт.** Если CLI начнёт
возвращать токены в исходной шкале, наш пересчёт нужно убрать. Если изменится формат
лога, нужно адаптировать его разбор. Ни один вариант нельзя считать исправным
только по успешному завершению команды: сравнить таймкоды с исходным звуком.

Токены не являются точными границами слов. Очень тихие и короткие реплики могут
не попасть в VAD; настройку чувствительности проверять также на повторы фраз.

## Нарезка субтитров

`cut_segment` режет только сегменты длиннее `MAX_MS = 7000` мс или
`MAX_CHARS = 90` знаков. Разрез допускается перед токеном с ведущим пробелом.
Сначала используются границы предложений с упаковкой соседних коротких частей,
затем деление по запятой или слову ближе к середине по времени.
По возможности обе части содержат не менее `MIN_CHARS = 20` знаков.

Длительность токена ограничивается `WORD_MS = 1500` мс. Края куска подрезаются
по интервалам `speech`, перекрытым им не менее чем на `OVERLAP_MS = 200` мс.
Решение о разрезании принимается по длительности после подрезки.
Короткие сегменты остаются без изменений; отдельные случаи могут превышать лимит.

Нарезка меняет TXT/SRT, но не структуру сегментов Whisper в JSON. Конкатенация
текстов субтитров должна сохранять текст соответствующего сегмента с заменами.

## Замены

Общий файл `замены.txt` находится рядом со скриптом. Проектные файлы ищутся
от папки клипа вверх; ближайшее к клипу определение имеет приоритет.

Формат: `вариант | вариант -> верно`; строки с `#` — комментарии.
Совпадения ограничены целыми словами через `(?<!\w)…(?!\w)`.
Все варианты объединены в одну регулярку, длинные идут первыми; замены не каскадируют.

Вариант со строчной буквы допускает заглавную первую букву. Результат тогда тоже
начинается с заглавной, кроме названий и команд со строчной латинской буквы.

Замены применяются ко всему сегменту с метками разрезов U+E000… перед разбиением
на отдельные субтитры. Пробел в шаблоне допускает метку перед собой; если замена
поглощает метку, соседние куски склеиваются. Учитывать, что `re.escape` экранирует
пробел как `\ `.

В JSON `text` содержит исправленный текст, а `text_raw` — исходный, только когда
он отличается. Повторные замены считаются от `text_raw`. Токены не изменяются.
Повторная сборка с теми же правилами должна оставлять файлы без изменений.

## Подсказка

Использовать короткое приветствие, имя и 2–3 главных термина; остальные исправлять
списком замен. Whisper принимает до 223 токенов подсказки и у длинной отбрасывает
начало. Передаётся `--carry-initial-prompt`; действие подсказки на длинных клипах
требует проверки по материалу. Не включать слова, которые в записи не звучат.
