# Fusion Templates

| Категория | Инструмент | Статус |
| --- | --- | --- |
| Effects | [Edge Aberration](effects/edge-aberration/README.md) | Готов |
| Effects | [Film Grain Look](effects/film-grain-look/README.md) | На проверке |
| Generators | [Type Drift](generators/type-drift/README.md) | На проверке |

## Единый подход к подключению

В папке каждого инструмента — `install`. Из корня репозитория, оболочка Bash:

```bash
bash resolve/fusion/templates/effects/edge-aberration/install
```

На macOS установщик создаёт симлинк в пользовательской папке Fusion:
`~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Templates/Edit/Effects/vt`.
Генераторы устанавливаются аналогично в `Edit/Generators/vt`.
Таким образом все наши шаблоны собраны в группе `vt` соответствующей категории.
Репозиторий должен оставаться на месте. Повторный запуск распознаёт подключение;
чужой файл или другой симлинк с тем же именем не заменяется.
Ссылка ведёт непосредственно на `.setting` в папке инструмента.

Можно явно передать другую папку назначения, например для проверки:

```bash
bash resolve/fusion/templates/effects/edge-aberration/install "scratchpad/resolve test/Effects"
```

Явно переданная папка используется как есть; `vt` к ней не дописывается.

Это не автоматическая поддержка другой ОС: стандартные пути настроены только
для macOS. Windows/Linux и создание симлинков в выбранной Bash-среде требуют проверки.
Установка не запускает Resolve, не обрабатывает медиа и не устанавливает шрифты.

## Использование и удаление

Перезапустить Resolve, найти шаблон по имени в Effects Library. Уже добавленный
на таймлайн экземпляр хранит свою копию: изменение исходника действует на новые применения.
Для отключения удалить только соответствующий симлинк из пользовательской папки
Fusion. Не удалять шаблон из репозитория или всю папку Effects/Generators.
Перед удалением проверить, что это именно симлинк на наш инструмент.

## Проверка

Установщик должен создавать прямую ссылку в группе `vt`, безопасно переносить
повторный запуск и сохранять чужие файлы. Эти условия проверяются
[тестами установщиков](../../../tests/README.md).
Визуальный результат и рендер проверяются отдельно в Resolve.

## Реализация

`install-template` — общий внутренний Bash-помощник. Установщики инструментов
передают ему путь к шаблону и категорию; общие проверки находятся в одном месте.
`.setting` хранится в Git, даже если собирается кодом: применение шаблона не требует сборщика.
