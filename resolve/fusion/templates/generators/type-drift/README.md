# Type Drift — финальный кадр для Resolve

Генератор: [Type Drift.setting](./Type%20Drift.setting). Чёрный фон,
серый малоконтрастный контур `ivanpotylitcyn.ru`, JetBrains Mono ExtraBold,
диагональ 22°, 13 независимо движущихся рядов и монохромное зерно поверх.
Центральный ряд по умолчанию движется медленнее остальных вправо-вверх
вдоль диагонали. Это первая версия с зерном; пыли и царапин в ней нет.

Используются родные узлы Fusion: sText, sDuplicate, sTransform, sMerge,
sRender, Background, Merge, FilmGrain. Внешние плагины, Studio API,
изображения и предварительный рендер не нужны. Структура и имена входов
сверены со штатными шаблонами установленного Resolve 21.1.

**Статус: на проверке.** Структурные проверки выполнены; подтверждения визуального результата и рендера пока нет. Проверки Windows/Linux не выполнены.

Команды ниже выполняются из корня репозитория.

## Подключение на macOS

1. Установи **JetBrains Mono**, если его ещё нет, со стилем **ExtraBold**.
   Resolve должен увидеть установленный шрифт после перезапуска.
2. В терминале выполни:

   ```bash
   bash resolve/fusion/templates/generators/type-drift/install
   ```

   Команда создаёт симлинк в пользовательской папке
   `Fusion/Templates/Edit/Generators/vt`. Чужой файл с тем же именем
   она не заменяет. Сам репозиторий должен оставаться на месте.
3. Перезапусти Resolve. На странице **Edit** открой **Effects → Generators**,
   найди **Type Drift** поиском. Он может отображаться в разделе
   **Fusion Generators / vt**.
4. Перетащи генератор в конец таймлайна. Начни с 5–8 секунд и формата 16:9.
5. Выдели клип и открой **Inspector → Generator**. Настройки сгруппированы
   по страницам **Text**, **Look**, **Motion**.

Подключать генератор через Import Timeline или класть на Adjustment Clip
не нужно: это самостоятельный клип с собственным фоном.

## Настройки

| Страница / ручка | Что меняет |
|---|---|
| Text / Text | Общий текст всех повторов |
| Font, Style | По умолчанию JetBrains Mono / ExtraBold; можно выбрать другой шрифт |
| Text size | Размер букв; начальное значение 0,085 |
| Outline thickness | Толщина контура; начальное значение 0,012 |
| Repeat spacing | Шаг повторов вдоль строки, в долях ширины кадра; изначально 1,05 |
| Row spacing | Расстояние между рядами до поворота; изначально 0,095 |
| Angle | Угол поля; изначально 22° |
| Look / Text color | Цвет контура; изначально RGB 0,16 / 0,16 / 0,16 |
| Background | Цвет фона; изначально чёрный |
| Grain strength | Сила зерна, изначально 0,025; 0 выключает фактуру |
| Grain size | Размер зерна, изначально 1,2 |
| Motion / Speed | Общая скорость, в ширинах кадра в секунду; изначально 0,08 |
| Center multiplier | Множитель центрального ряда; изначально +0,2 |
| Above 1…6 multiplier | Ряды выше центрального, от ближайшего к дальнему, до поворота |
| Below 1…6 multiplier | Ряды ниже центрального, от ближайшего к дальнему, до поворота |

Положительный множитель означает движение вправо вдоль строки, при
положительном угле — также вверх. Отрицательный меняет направление;
ноль останавливает ряд. Скорость ряда = Speed × его множитель.
Например, центральный ряд при 0,08 × 0,2 проходит 1,6% ширины кадра
в секунду. У соседних по умолчанию +1,6 и −1,8.

После смены текста или размера подстрой **Repeat spacing**, чтобы между
надписями был небольшой зазор: шаг фиксированный и не измеряет ширину
новой надписи автоматически. Слишком маленький шаг даст наложение букв,
слишком большой — длинные пустые промежутки. Лучше вводить одну строку.

Для первого просмотра оставь Angle 22° и Row spacing 0,095. Большой шаг
делает поле реже. При очень большом угле или необычном формате кадра
проверь заполнение углов: число рядов фиксировано, 13.

## Длительность и монтаж

Длину меняй обычным растягиванием края генератора на таймлайне.
Скорость рассчитывается по секундам и FPS композиции, независимо от
конечного кадра: удлинение клипа не растягивает анимацию. Ряды переходят
на соседний одинаковый повтор, поэтому полоса текста не должна закончиться
даже при длинном клипе. Это непрерывное движение, а не общий цикл заданной
длины: последний кадр не обязан совпадать с первым у всех рядов и зерна.

Появление и уход можно сделать обычными ручками fade клипа на странице Edit.
Если предпросмотр тяжёлый, включи Render Cache для генератора либо временно
поставь Grain strength = 0. Конечный рендер делай после возврата зерна.

Изменения файла шаблона видны в **новых экземплярах** после перезапуска
Resolve. Уже лежащий на таймлайне генератор хранит собственную копию узлов.
Для удаления подключения удали только симлинк Type Drift.setting из
пользовательской папки Generators/vt; установщик другие эффекты не трогает.

## Проверка первой версии

Генератор не отрендерен в Resolve в этой сессии: внешний скриптинг бесплатной
версии недоступен, GUI по правилам репозитория не использовался. Выполнены
проверки структуры файла, ссылок между узлами, формулы повторения и установщика
в отдельной временной папке. При первом применении проверь:

- надписи контурные, JetBrains Mono действительно выбран;
- центральный ряд идёт медленно вверх по диагонали, соседние — быстрее;
- на 5 и 15 секундах поле заполнено, при переходе повтора нет скачка;
- изменение Text и Text color действует на всё поле;
- Grain strength = 0 убирает зерно.

Для разработчика: [build.rb](./build.rb) воспроизводит
файл шаблона командой `ruby --disable-gems resolve/fusion/templates/generators/type-drift/build.rb`
из корня репозитория. Установка генератора Ruby не требует.

Установщик принимает необязательный путь к папке назначения: `bash resolve/fusion/templates/generators/type-drift/install "/путь/к/Generators"`. Общие правила подключения и удаления — в [инструкции шаблонов](../../README.md).
