# DaVinci Resolve

Инструменты, специально предназначенные для Resolve.
Сейчас реализованы [шаблоны Fusion](fusion/README.md).

| Направление | Содержимое | Состояние |
| --- | --- | --- |
| `fusion/` | Шаблоны, эффекты и генераторы Fusion | Есть инструменты |
| `timelines/` | Создание и преобразование FCPXML/EDL | В плане; папки пока нет |
| `markers/` | Маркеры по тексту и монтажным заметкам | В плане; папки пока нет |
| `color/` | LUT и вспомогательные инструменты цвета | Добавить при первой задаче |

Рабочая среда — бесплатный Resolve 21.1 на macOS. Подход основан на файлах,
без внешнего API Studio. Готовность каждого инструмента указана в его README.
Шаблоны подключаются напрямую из папок инструментов в группу `vt` в библиотеке
Resolve. [Установка и удаление](fusion/templates/README.md).
