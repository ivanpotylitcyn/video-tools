# video-tools — контекст для Claude

Иван Потылицын снимает видео (разработка электроники, обучающие ролики, трансляции) и монтирует в DaVinci Resolve. Этот репозиторий — инструменты, с которыми Claude помогает монтировать: расшифровка, а дальше таймлайны, маркеры и оверлеи. Общаться с Иваном по-русски.

## Правила работы

- **Боевые прогоны запускает Иван сам.** Не запускать расшифровку (и любую обработку) на настоящих папках с исходниками. Тестировать в scratchpad на 2–3 коротких клипах, подключённых симлинками. На настоящих папках можно запускать только `-n` (пробный прогон, ничего не пишет). Результат работы — готовая команда для Ивана.
- **Исходники неприкосновенны.** Ничего не перезаписывать и не удалять в `src/`. Скрипты пишут только новые файлы рядом с исходниками.
- **Всё локально и офлайн.** Никаких облачных API для распознавания. Сеть — только для установки.
- **Конвейер в терминале**, а не GUI-приложения: прозрачно и повторяемо.
- Сначала обкатать вручную, потом автоматизировать осознанно.

## Исходники

```
<проект>/video/src/<месяц.день>/<камера>/клип.MP4
```

Пример: `/Volumes/potylitcyn/2026/10.11 - Спутник/video/src/10.11/DOP3/`.

Сверено с диском 10.11.2026: видео всегда лежит ровно на уровне камеры. Исключение — «04.04 - Регата Века»: там нет уровня `src/` (`video/04.08/DOP3`). Рядом с камерами бывают папки звука (DM2, RWG2L/R, ZH6, MSB — только WAV) и прочее (PDF/). Скрипт берёт только видео.

Камеры: **DOP3** — Pocket 3; **C5DM4** — MOV, PCM стерео; **CM6M2** — MP4, AAC стерео; **OBS** — MKV; **VK** — скачанное видео (44.1 кГц).

- Диск с проектами — **exFAT**: не различает регистр (`a.wav` == `a.WAV`), macOS создаёт служебные `._*` файлы. Их нужно игнорировать.
- **DOP3 = DJI Osmo Pocket 3.** Видео — HEVC 4K 23.976 fps, звук AAC 48 кГц (одинаковый в обоих каналах). В видео пишется **микрофон, голос там лучше**. Камера также пишет `клип.WAV` (48 кГц, стерео) и `клип.LRF` (прокси). Иван раскладывает их в `wav/` и `lrf/`. Камерные WAV для расшифровки **не использовать** — так решил Иван. WAV и LRF не всегда разложены по `wav/` и `lrf/`: в старых проектах (03.17, 06.04, 06.14) они лежат прямо рядом с MP4.
- **Slow-mo Pocket 3** (Команда 09.17/09.18): в MP4 нет звука, рядом `клип.AAC` в реальном времени (видео в 4 раза длиннее). Таймлапсы (Дагестан 06.15): звука нет вовсе. Такие клипы скрипт пропускает.

## transcribe

Bash-скрипт (bash 3.2 из macOS: без `mapfile`, без ассоциативных массивов). Зависимости: `ffmpeg`, `ffprobe`, `whisper-cli` (whisper.cpp 1.9.5, формула Homebrew теперь называется `whisper.cpp`), `python3`, модели `~/whisper-models/ggml-large-v3-turbo.bin` и `~/whisper-models/ggml-silero-v6.2.0.bin` (VAD).

Как работает:
1. Находит видео в папке (mp4/mov/m4v/mkv/mts/mxf/avi, регистр любой, `._*` пропускает).
2. Папка обходится рекурсивно (скрытые папки пропускаются), так что передаётся `video/src` целиком. В каждой папке с видео результаты лежат в подпапках `audio/ txt/ srt/ json/` — всегда, даже если видео одно: одна раскладка для всех и нет коллизии с камерным `клип.WAV` рядом с MP4.
3. Извлекает звук из видео: `ffmpeg -map 0:a:0 -vn -ar 16000 -ac 1 -c:a pcm_s16le` → `audio/клип.wav`. Папка называется `audio`, а не `wav`, потому что `wav/` занята камерными WAV, а exFAT не различает регистр. Существующий WAV переиспользуется, только если он 16 кГц моно. Иначе это чужой файл: клип пропускается с ошибкой.
4. `whisper-cli -l ru --vad -vm <silero> -otxt -osrt -ojf` пишет во временную папку. Без `-np`: из stderr нужны строки `vad_segment_info`. Затем пересчитываются токены в JSON (см. ниже), и результаты переносятся в `txt/ srt/ json/`.
5. Клип пропускается, если результаты уже есть (`json` непустой, `txt`/`srt` могут быть пустыми — в клипе нет речи; `-f` — пересчитать) (`-f` — пересчитать) или если в видео нет звуковой дорожки.
6. В конце — итог; с `-n` — план: сколько клипов и часов видео.

Опции: `-n` пробный прогон, `-p` подсказка (initial prompt), `-l` язык, `-f` пересчёт.

Что выяснили на тестах (10.11.2026, Pocket 3):
- Скорость: 15 секунд речи — около 2–3 секунд вместе с загрузкой модели.
- Без `-p` текст может выйти без пунктуации, а «Потылицын» превращается в «Пателицын». Подсказка вроде `"Привет, друзья! На связи Иван Потылицын."` исправляет и то и другое.
- На 2-секундном клипе без речи Whisper выдумал текст «Субтитры создавал DimaTorzok». Типичная ошибка Whisper на тишине. С VAD — пусто.

VAD (подключён 10.11.2026, Silero v6.2.0, настройки по умолчанию):
- Сегменты (SRT, `offsets` сегментов в JSON) whisper-cli сам переводит в шкалу исходного файла. Проверено: 12,3 с тишины перед клипом сдвигают всё ровно на 12,3 с.
- **Баг whisper-cli 1.9.5:** токены в JSON остаются в шкале «склеенной речи» (cli берёт `whisper_full_get_token_data`, а не `whisper_full_get_token_t0/t1`). К концу клипа ошибка доходит до секунд. Скрипт (`fix_vad_json`) пересчитывает их тем же алгоритмом, что и библиотека, по строкам `vad_segment_info` из лога (целые сотые секунды, без потерь). Границы речи сохраняются в JSON как `speech`. Если в новой версии whisper.cpp cli это починит, пересчёт надо убрать: он станет двойным.
- Таймкоды токенов с VAD точнее, чем без него: без VAD Whisper растягивает токены на весь файл, включая тишину по краям (проверено нарезкой фрагментов).
- С VAD текст делится на фразы, и пунктуации больше. Мягкие настройки (`-vp 200`) на тестах давали повтор фразы, поэтому оставлены значения по умолчанию.

## Монтаж с Claude (общий план)

Claude не смотрит видео. Он работает с транскриптом и таймкодами, стоп-кадрами (`ffmpeg`) и кодом.

**Resolve бесплатный (21.1):** внешний скриптинг и MCP-интеграция есть только в Studio. Поэтому всё через файлы:
- таймлайн FCPXML/EDL → File → Import → Timeline (создаёт новый таймлайн);
- маркеры;
- клипы-оверлеи с прозрачностью (ProRes 4444) на дорожку V2.

**Оверлеи — Remotion** (React → видео, нужен Node.js). Перед рабочим использованием проверить условия лицензии.

Очередь задач:
1. **Клавиатурные сокращения.** Найти в транскрипте «команд-шифт-пэ» → `⌘⇧P` с таймкодом. Сначала маркеры в Resolve, потом анимированные плашки.
2. **Тезисы к разборам заданий методички.** Claude читает транскрипт вместе с методичкой, предлагает плашки (тезисы, термины, код, формулы) с таймкодами. Иван правит список, Claude рендерит в едином шаблоне.
3. **Слайды докладчиков.** Найти смены слайдов на видео, сопоставить с PNG, собрать FCPXML: видео на V1, PNG на V2.

Отложено:
- **WhisperX** — точные таймкоды слов (выравнивание через wav2vec2, на Маке только CPU). Гибрид: распознавать whisper.cpp, выравнивать WhisperX, когда понадобится резка по словам.
- **ButterCut** — посмотреть его генератор FCPXML как справочник.
- **Resolve Studio** — если монтаж с Claude приживётся.

## Запись (справочно)

- Трансляции: ATEM Mini Pro ISO. Работаем с мастером (аппаратный PiP), ISO пишется как страховка. Вариант на будущее: экран пишет OBS, камера и звук — ATEM, Claude синхронизирует файлы по звуку.
- Звук с Мака: `ffmpeg -f avfoundation -i ":MacBook Pro Microphone" -ac 1 -c:a aac -b:a 128k запись.m4a`. Устройство указывать по имени: номера меняются.
- Мак: M2 Pro, whisper.cpp работает через Metal.
