# video-tools — контекст для Claude

Иван Потылицын снимает видео (разработка электроники, обучающие ролики, трансляции) и монтирует в DaVinci Resolve. Его команда — **ant-lab**: всегда строчными и через дефис (не AntLab). Сайт программы «Встраиваемые системы» — es.ant-lab.ru, методичка — github.com/ant-lab-ru/es-book. Этот репозиторий — инструменты, с которыми Claude помогает монтировать: расшифровка, а дальше таймлайны, маркеры и оверлеи. Общаться с Иваном по-русски.

## Правила работы

- **Боевые прогоны запускает Иван сам.** Не запускать расшифровку (и любую обработку) на настоящих папках с исходниками. Тестировать в scratchpad на 2–3 коротких клипах, подключённых симлинками. На настоящих папках можно запускать только `-n` (пробный прогон, ничего не пишет). Результат работы — готовая команда для Ивана.
- **Исходники неприкосновенны.** Ничего не перезаписывать и не удалять в `src/`. Скрипты пишут только новые файлы рядом с исходниками.
- **Всё локально и офлайн.** Никаких облачных API для распознавания. Сеть — только для установки.
- **Конвейер в терминале**, а не GUI-приложения: прозрачно и повторяемо.
- Сначала обкатать вручную, потом автоматизировать осознанно.

## Исходники

```
<проект>/video/src/<месяц.день>/<камера>/клип.MP4
```

Пример: `/Volumes/potylitcyn/2026/10.11 - Спутник/video/src/10.11/DOP3/`.

Сверено с диском 10.11.2026: видео всегда лежит ровно на уровне камеры. Исключение — «04.04 - Регата Века»: там нет уровня `src/` (`video/04.08/DOP3`). Рядом с камерами бывают папки звука (DM2, RWG2L/R, ZH6, MSB — только WAV) и прочее (PDF/). Скрипт берёт только видео.

Камеры: **DOP3** — Pocket 3; **C5DM4** — MOV, PCM стерео; **CM6M2** — MP4, AAC стерео; **OBS** — MKV; **VK** — скачанное видео (44.1 кГц).

- Диск с проектами — **exFAT**: не различает регистр (`a.wav` == `a.WAV`), macOS создаёт служебные `._*` файлы. Их нужно игнорировать.
- **DOP3 = DJI Osmo Pocket 3.** Видео — HEVC 4K 23.976 fps, звук AAC 48 кГц (одинаковый в обоих каналах). В видео пишется **микрофон, голос там лучше**. Камера также пишет `клип.WAV` (48 кГц, стерео) и `клип.LRF` (прокси). Иван раскладывает их в `wav/` и `lrf/`. Камерные WAV для расшифровки **не использовать** — так решил Иван. WAV и LRF не всегда разложены по `wav/` и `lrf/`: в старых проектах (03.17, 06.04, 06.14) они лежат прямо рядом с MP4.
- **Slow-mo Pocket 3** (Команда 09.17/09.18): в MP4 нет звука, рядом `клип.AAC` в реальном времени (видео в 4 раза длиннее). Таймлапсы (Дагестан 06.15): звука нет вовсе. Такие клипы скрипт пропускает.

## transcribe

Bash-скрипт (bash 3.2 из macOS: без `mapfile`, без ассоциативных массивов). Зависимости: `ffmpeg`, `ffprobe`, `whisper-cli` (whisper.cpp 1.9.5, формула Homebrew теперь называется `whisper.cpp`), `python3`, модели `~/whisper-models/ggml-large-v3-turbo.bin` и `~/whisper-models/ggml-silero-v6.2.0.bin` (VAD).

Как работает:
1. Находит видео в папке (mp4/mov/m4v/mkv/mts/mxf/avi, регистр любой, `._*` пропускает).
2. Папка обходится рекурсивно (скрытые папки пропускаются), так что передаётся `video/src` целиком. В каждой папке с видео результаты лежат в подпапках `audio/ txt/ srt/ json/` — всегда, даже если видео одно: одна раскладка для всех и нет коллизии с камерным `клип.WAV` рядом с MP4.
3. Извлекает звук из видео: `ffmpeg -map 0:a:0 -vn -ar 16000 -ac 1 -c:a pcm_s16le` → `audio/клип.wav`. Папка называется `audio`, а не `wav`, потому что `wav/` занята камерными WAV, а exFAT не различает регистр. Существующий WAV переиспользуется, только если он 16 кГц моно. Иначе это чужой файл: клип пропускается с ошибкой.
4. `whisper-cli -l ru --vad -vm <silero> -pp -ojf` пишет JSON во временную папку. Без `-np`: из stderr нужны строки `vad_segment_info`; stderr идёт через `progress_bar` (лог + полоска из строк `progress = N%`). Затем `postprocess.py vad` пересчитывает токены (см. ниже), JSON переносится в `json/`, а `postprocess.py render` применяет замены и собирает `txt/` и `srt/` (формат побайтно как у whisper-cli — проверено на 23 настоящих расшифровках).
5. Клип пропускается, если результаты уже есть (`json` непустой, `txt`/`srt` могут быть пустыми — в клипе нет речи; `-f` — пересчитать) или если в видео нет звуковой дорожки. У готовых клипов в первом проходе проверяется (`render --check`), изменят ли что-то списки замен; если да — txt/srt/json пересобираются без whisper.
6. Работает в два прохода: сначала план (очередь в `$TMP/queue`, с `-n` на нём и останавливается), затем распознавание со строкой прогресса после каждого клипа: клипы и минуты готово/осталось, оценка времени.

Опции: `-n` пробный прогон, `-p` подсказка (initial prompt), `-l` язык, `-f` пересчёт.

Нарезка субтитров (`postprocess.py`, `cut_segment`, сделано 10.11.2026; `-ml` whisper-cli не используем — он требует перезапуска whisper и меняет JSON):
- Режется только сегмент длиннее `MAX_MS` = 7 с или `MAX_CHARS` = 90 знаков. Разрез — только перед токеном с ведущим пробелом (иначе разрезали бы «es.ant-lab.ru»). Сначала по концам предложений с упаковкой соседних коротких обратно, затем `halve`: запятая, потом слово, ближе к середине по времени, обе части ≥ `MIN_CHARS` = 20, если можно.
- Время куска — по токенам: длительность токена ограничена `WORD_MS` = 1,5 с (whisper растягивает токен у паузы на всю паузу, бывало 22 с на «вот,»), затем края подрезаются по участкам `speech`, которые кусок перекрывает ≥ `OVERLAP_MS` = 200 мс. Длина для решения «резать ли» считается уже после подрезки.
- JSON не меняется (там сегменты whisper как есть), нарезка — только в txt/srt. Короткие сегменты whisper не трогаются.
- Проверено на «ВС» (обе версии) и Спутнике: текст субтитров склеивается ровно в текст JSON, повторная сборка ничего не меняет. Новая «ВС»: 328 сегментов → 1156 субтитров, медиана 3,8 с; длиннее 7 с остался 1 («Ну,» поровну перекрывает речь до и после паузы — неразрешимо по данным).

Замены (`замены.txt`, `postprocess.py`):
- Общий список — в репозитории рядом со скриптом; проектные — в папке клипа и выше (обычно `<проект>/video/замены.txt`). Ближний к клипу главнее.
- Строка: `вариант | вариант -> верно`, `#` — комментарий. Целые слова (`(?<!\w)…(?!\w)`), одна регулярка на все варианты, длинные первыми, — замены не каскадируют. Применяются ко всему сегменту с метками разрезов (символы U+E000…, по одному на разрез); пробел в шаблоне допускает метку перед собой, съеденная заменой метка склеивает куски. Внимание: `re.escape` экранирует пробел как `\ `. Вариант с маленькой буквы срабатывает и с большой; замена тогда тоже с большой, кроме замен со строчной латинской буквы (`ant-lab`, `git pull` — названия и команды).
- В JSON: `text` — с заменами, `text_raw` — как распознал whisper (поле есть, только если текст отличается). Замены всегда считаются от `text_raw`, поэтому повторный прогон идемпотентен. Токены не трогаются.
- Список «Встраиваемых систем» заведён 10.11.2026: `/Volumes/potylitcyn/2026/09.02 - Встраиваемые системы/video/замены.txt` (внизу закомментированы места, которые Иван должен проверить на слух).

Что выяснили на тестах (10.11.2026, Pocket 3):
- Скорость: 15 секунд речи — около 2–3 секунд вместе с загрузкой модели.
- Без `-p` текст может выйти без пунктуации, а «Потылицын» превращается в «Пателицын». Подсказка вроде `"Привет, друзья! На связи Иван Потылицын."` исправляет и то и другое.
- Подсказка: лимит 223 токена ≈ 550–600 знаков русского текста (716 знаков = 270 токенов); у длинной whisper отбрасывает начало. Скрипт передаёт `--carry-initial-prompt`: без него подсказка живёт только в начале клипа (окно контекста 224 токена вытесняется распознанным текстом), а у Ивана бывают клипы по 25 минут. Утечки текста подсказки в расшифровку на тестах нет. Действие на длинном клипе пока не проверено.
- **Длинная подсказка дробит текст хуже и теряет фразы** (10.11.2026). «Встраиваемые системы», 80 мин: подсказка на 40 знаков — 2016 сегментов, медиана 1,7 с, максимум 8,5 с; подсказка-список терминов на 385 знаков — 328 сегментов, медиана 10 с, максимум 50 с, и выпали две короткие фразы. Спутник: 226 → 129 сегментов. Вывод: подсказка — короткая (приветствие + имя + 2–3 главных термина), остальное — списком замен.
- Порядок работы с подсказками: базовая подсказка → Claude читает расшифровки, ищет искажённые термины → подсказка проекта → `-f`.
- На 2-секундном клипе без речи Whisper выдумал текст «Субтитры создавал DimaTorzok». Типичная ошибка Whisper на тишине. С VAD — пусто.

VAD (подключён 10.11.2026, Silero v6.2.0, настройки по умолчанию):
- Сегменты (SRT, `offsets` сегментов в JSON) whisper-cli сам переводит в шкалу исходного файла. Проверено: 12,3 с тишины перед клипом сдвигают всё ровно на 12,3 с.
- **Баг whisper-cli 1.9.5:** токены в JSON остаются в шкале «склеенной речи» (cli берёт `whisper_full_get_token_data`, а не `whisper_full_get_token_t0/t1`). К концу клипа ошибка доходит до секунд. Скрипт (`postprocess.py vad`) пересчитывает их тем же алгоритмом, что и библиотека, по строкам `vad_segment_info` из лога (целые сотые секунды, без потерь). Границы речи сохраняются в JSON как `speech`. Если в новой версии whisper.cpp cli это починит, пересчёт надо убрать: он станет двойным.
- Таймкоды токенов с VAD точнее, чем без него: без VAD Whisper растягивает токены на весь файл, включая тишину по краям (проверено нарезкой фрагментов).
- С VAD текст делится на фразы, и пунктуации больше. Мягкие настройки (`-vp 200`) на тестах давали повтор фразы, поэтому оставлены значения по умолчанию.

## Монтаж с Claude (общий план)

Claude не смотрит видео. Он работает с транскриптом и таймкодами, стоп-кадрами (`ffmpeg`) и кодом.

**Resolve бесплатный (21.1):** внешний скриптинг и MCP-интеграция есть только в Studio. Поэтому всё через файлы:
- таймлайн FCPXML/EDL → File → Import → Timeline (создаёт новый таймлайн);
- маркеры;
- клипы-оверлеи с прозрачностью (ProRes 4444) на дорожку V2.

**Оверлеи — Remotion** (React → видео, нужен Node.js). Перед рабочим использованием проверить условия лицензии.

Первый монтаж (10.11.2026, «Встраиваемые системы», трансляция из VK → `out/introduction.mp4` для YouTube):
- Без Resolve: ffmpeg `select`/`aselect` по списку оставленных кусков. Куски = участки речи VAD (`speech` из JSON) минус вырезки по смыслу; паузы > 1,5 с укорачиваются до 0,6 с (0,35 после фразы + 0,25 перед следующей).
- Синхрон: все границы на кадрах (кратно 1/30 с), звук режется `asetnsamples=n=1470` (один кадр при 44,1 кГц), условие со сдвигом на полкадра — звук и видео выбирают одни и те же кадры, дрейфа нет (длины совпали до кадра).
- Границы вырезок по субтитрам точны до ~0,1 с и часто внутри сплошной речи VAD — каждую границу сдвигали к самому тихому кадру рядом (RMS по `audio/*.wav`). Проверка: whisper по ±3 с вокруг каждого стыка — все 27 стыков чистые.
- Вырезки по смыслу Claude выбирает по транскрипту: ожидание зрителей, фальстарт, замена батареек, возня с демонстрацией экрана, «вижу плюсы», «мы ещё на связи», дубли фраз, отсылки ко времени трансляции. Иван выбрал «средне»; длинных пауз у Ивана мало (41 на 80 минут), основное сокращение — смысловое: 1:20 → 1:09.
- Кодирование: libx264 `-preset slow -crf 17`, 1080p30, AAC 256k; ~16 мин на M2 Pro (129 к/с). Громкость: исходник −21,8 LUFS → `volume=+7.8dB` + `alimiter` −1,5 дБ (loudnorm ушёл бы в динамический режим) → −14,1 LUFS.
- Качество: из веба (VK, 1,1 Мбит/с) лучше не сделать; апскейл до 1440p ради кодека YouTube Иван отклонил — выигрыш мал при таком исходнике. **Дальше монтируем из аппаратной мастер-копии ATEM**, а не из веба.
- Заодно: субтитры смонтированной версии (`out/introduction.srt`, пересчёт времени по списку кусков) и оглавление для описания.
- Правка 11.11.2026: в начале остался хвост «Ну что?» — «то» (токены whisper врали: «Зд» на 122,86, а слово по громкости с 123,38). Начало перенесли на 123,20 по графику RMS. Привязка к тишине выбрала бы 123,07 — тихо, но в 0,04 с после «то»; поэтому в `cuts.txt` время с `!` на конце ставится точно, без привязки. Перерендер из исходника (не обрезка готового — одно поколение сжатия), субтитры и оглавление пересчитаны (−0,5 с).
- Скрипты пока в scratchpad (обкатка вручную); вынести в репозиторий, когда подход повторится.

Короткие вертикальные клипы (11.11.2026, 4 шортса из «Встраиваемых систем»):
- Раскладка у Ивана: `out/` — всё по проекту; `out/<исходник>/` (например `out/intro/` — из «Знакомства»); внутри папка на каждый ролик со своими файлами: `short-15/short-15.mp4`, `.srt`, `.txt` (название и описание). Основное видео — `out/intro/intro/`.
- Формат: 1080×1920, полоса 608×1080 из кадра 16:9 (`crop=608:1080:630:0`, лицо чуть левее центра), увеличение lanczos. Заголовок-крючок на тёмной плашке сверху (y≈230) — только первые 6 с, затем гаснет за 0,5 с (отдельный слой: `-loop 1 -t 6.5 -i title.png`, `fade=t=out:alpha=1`); на весь клип Ивану не понравилось — висит «во лбу». Клип заканчивать на законченной фразе с точкой и 0,3 с паузы после. Субтитры по 2–4 слова (≤18 знаков), SF Pro Heavy 92 px, белые с чёрной обводкой 8 px, y≈1240.
- **ffmpeg из Homebrew без libass/freetype**: фильтров `subtitles`/`drawtext` нет. Субтитры рисуются Pillow (`/System/Library/Fonts/SFNS.ttf`, вариация по имени) в прозрачные PNG на весь кадр; concat-список с длительностями → `overlay`. Без установки чего-либо.
- Замены и правки (цифры, «ЛПНТ», «ant-lab») применять ко всему тексту куска до нарезки на субтитры, время слов переносить выравниванием (difflib) — иначе фраза, разрезанная границей субтитров, не заменится. Субтитры строго друг за другом: перекрытия в concat-списке накапливают сдвиг.
- Таймкоды токенов на границах врут (слипаются) — границы клипов ставить по RMS звука. Но тихий кадр бывает смычкой согласной внутри слова («ч-т-о»): проверять whisper'ом отрывок исходника с выбранной точки.
- **Whisper дописывает начало фразы по смыслу**: клип с «микроконтроллеры программировать…» он слышит как «потому что микроконтроллеры…», даже если отрывок начинается после начала «м». Проверка — громкость первых 100 мс клипа против исходника; и распознавание исходника с этой точки. На длинных клипах целиком whisper пропускает фразы — проверять кусками по 3–5 с.
- Обложки (`<клип>-cover.jpg`, 1080×1920, JPG ~250 КБ — лимит YouTube 2 МБ): кадр с живой мимикой и взглядом в камеру (выбор по контактному листу из 12 кадров), затемнение снизу, главный текст SF Pro Black 150 px с акцентным словом жёлтым (#FFD400), под ним подпись 64 px; блок текста с y≈1060 — ниже лица, выше интерфейса. Текст обложки короче и ярче заголовка в клипе («НАЧНИТЕ В 15», «5 АВОКАДО», «ant-lab — НЕ МУРАВЬИ», «КТО ТАКОЙ ИНЖЕНЕР?»). Скрипт `cover.py` в scratchpad.
- Рендер ~22 с на клип (x264 slow, CRF 18), число кадров совпадает с расчётом. Скрипт `clips.py` пока в scratchpad.

Очередь задач:
1. **Клавиатурные сокращения.** Найти в транскрипте «команд-шифт-пэ» → `⌘⇧P` с таймкодом. Сначала маркеры в Resolve, потом анимированные плашки.
2. **Тезисы к разборам заданий методички.** Claude читает транскрипт вместе с методичкой, предлагает плашки (тезисы, термины, код, формулы) с таймкодами. Иван правит список, Claude рендерит в едином шаблоне.
3. **Слайды докладчиков.** Найти смены слайдов на видео, сопоставить с PNG, собрать FCPXML: видео на V1, PNG на V2.

Отложено:
