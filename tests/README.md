# Проверки

Из корня репозитория, Python 3 без сторонних пакетов:

```bash
python3 -m unittest discover -s tests -v
```

Проверки установщиков создают временные папки и проверяют повторное подключение,
пути с пробелами, сохранность чужих файлов и симлинков, включая цепочки старых подключений.
Пользовательская папка Resolve и реальные медиаматериалы не затрагиваются.
Проверки требуют POSIX-среды с Bash; на нативном Windows пропускаются.
Визуальная проверка Fusion в Resolve остаётся за Иваном.
