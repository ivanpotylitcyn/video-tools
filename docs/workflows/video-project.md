# Работа с видеопроектом

## Где что хранится

Здесь — общие инструменты. В папке проекта — исходники, расшифровки, сценарий,
идеи, решения, разовые скрипты и результаты. Наличие Git в проекте не требуется.
Существующую раскладку проектов не перестраивать автоматически.

Типичная раскладка исходников:

```text
<проект>/video/src/<месяц.день>/<камера>/клип.MP4
```

Видео лежит на уровне камеры. Есть старые проекты без уровня `src/`:
скрипт принимает любую выбранную папку. Рядом бывают папки звука и PDF —
расшифровка выбирает только поддерживаемое видео.
В каждой папке с видео результаты расшифровки: `audio/`, `txt/`, `srt/`, `json/`.
Проектные замены — `<проект>/video/замены.txt` или ближе к клипам.
Не путать `video/txt/` со сценарием ролика и камерные `txt/` с расшифровками.

Монтажные данные и разовые скрипты могут жить в `video/resolve/work/`, FCPXML —
в `video/resolve/`. Музыка и Cubase — в `audio/` проекта. Готовые видео —
`video/out/`; для нескольких версий/роликов использовать вложенные папки.

## Особенности источников

- exFAT не различает регистр; `a.wav` и `a.WAV` могут быть одним файлом.
  Служебные `._*` и скрытые папки игнорировать.
- DOP3 — DJI Osmo Pocket 3, обычно HEVC 4K 23,976 fps, AAC 48 кГц.
  Для речи использовать микрофон из видео. Камерные WAV не использовать.
  WAV и LRF бывают в `wav/`, `lrf/` или рядом с MP4; поэтому извлечённый звук — в `audio/`.
- Slow-mo Pocket 3 бывает без звука в MP4, соседний AAC идёт в реальном времени,
  не в шкале замедленного видео. Таймлапсы тоже бывают без звука. Их пропускаем.
- C5DM4 — MOV/PCM стерео; CM6M2 — MP4/AAC стерео; OBS — MKV;
  VK — скачанное видео, встречается звук 44,1 кГц. Параметры проверять ffprobe.
- Для монтажа предпочитать аппаратную мастер-копию ATEM веб-версии. ISO — страховка.

## Монтаж по тексту

Иван читает транскрипт → ассистент предлагает текст ролика → Иван правит →
по согласованному тексту подбираются куски и собирается FCPXML.
Границы токенов Whisper у пауз могут ошибаться на секунды: опираться на VAD,
проверять RMS рядом с резом, затем короткий отрывок со стыком.
Тихое место может быть внутри согласной; повторное распознавание тоже не гарантирует
правильного начала. Проверять звук, не считать токены точной разметкой слов.
Полную обработку запускает Иван; конкретные вырезки и проверки хранить в проекте.

## Музыка

Сначала получить актуальное направление от Ивана. Прошлая композиция не задаёт
темп, гармонию и инструменты следующей. MIDI не содержит VST, семплы или аудиоэффекты.
Параметры музыкального редактора записывать в проекте; новые версии не перезаписывают старые.

## Запись

Трансляции — ATEM Mini Pro ISO; аппаратный PiP в мастере. Будущая альтернатива —
экран из OBS, камера и звук из ATEM, синхронизация по звуку.
На macOS устройство записи указывать по имени: номера avfoundation меняются.

```bash
ffmpeg -f avfoundation -i ":MacBook Pro Microphone" -ac 1 -c:a aac -b:a 128k запись.m4a
```

Это команда записи для Ивана, не автоматическая часть установки инструментов.
