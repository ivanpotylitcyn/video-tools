# video-tools

Инструменты для монтажа видео вместе с Claude. Всё работает локально и офлайн.

## transcribe — расшифровка

Извлекает звук из видео и распознаёт речь через whisper.cpp. На выходе текст, субтитры и JSON с таймкодами.

```bash
./transcribe -n ПАПКА                 # показать план, ничего не записывать
./transcribe -p "ПОДСКАЗКА" ПАПКА     # расшифровать
```

Папка обходится рекурсивно, поэтому обычно передают `video/src` целиком:

```bash
./transcribe -p "Привет, друзья! На связи Иван Потылицын." \
  "/Volumes/potylitcyn/2026/10.11 - Спутник/video/src"
```

Можно передать несколько папок (например, `/Volumes/potylitcyn/2026/*/video/src`) или отдельные файлы. Сначала скрипт печатает план: сколько клипов и сколько часов видео предстоит расшифровать (с `-n` на этом и останавливается). Дальше после каждого клипа идёт строка прогресса:

```
  [3/22] 10.11/DOP3/DJI_20261110104837_0159_D.MP4 (0:02)
      за 1 с · готово 3 из 22, 0:27 из 28:35 видео · осталось 19, 28:08, ещё ~6:40
```

«Ещё ~…» — оценка оставшегося времени по средней скорости с начала прогона. Пока клип распознаётся, под его строкой идёт полоска прогресса этого клипа с оценкой времени до его конца (данные whisper-cli `-pp`, шаг 5%).

### Опции

| Опция | Смысл |
|---|---|
| `-n` | пробный прогон: показать, что будет сделано |
| `-p ТЕКСТ` | подсказка для whisper (см. ниже) |
| `-l ЯЗЫК` | язык речи, по умолчанию `ru`; `auto` — определить самому |
| `-f` | пересчитать уже расшифрованные клипы |
| `-h` | справка |

Модель по умолчанию — `~/whisper-models/ggml-large-v3-turbo.bin`. Другую можно задать переменной `WHISPER_MODEL`.

### Куда кладутся результаты

В каждую папку, где лежит видео, с теми же именами. Раскладка всегда одинаковая, даже если видео в папке одно:

```
DOP3/клип.MP4
DOP3/audio/клип.wav
DOP3/txt/клип.txt
DOP3/srt/клип.srt
DOP3/json/клип.json
```

- `audio/` — звук из видео, WAV 16 кГц моно (формат, на котором обучен Whisper).
- `txt/` — чистый текст.
- `srt/` — субтитры (Resolve, плееры, YouTube).
- `json/` — подробный JSON с таймкодами слов-токенов: основа монтажа по тексту. В поле `speech` — участки речи, которые нашёл VAD (в миллисекундах от начала клипа).

### Как ведёт себя

- **Распознаётся только речь.** Перед Whisper работает фильтр речи VAD (Silero). Он вырезает тишину, поэтому Whisper не выдумывает на ней текст. Заодно субтитры разбиваются по фразам и точнее встают по времени. Если речи в клипе нет, txt и srt будут пустыми — это нормально.
- **Звук берётся из видео.** На Pocket 3 в видео пишется микрофон, на нём голос слышно лучше. Камерные WAV из `wav/` скрипт не использует.
- **Чужие файлы не трогает.** Извлечённый звук лежит в `audio/`, а не в `wav/`: exFAT не различает регистр, и `клип.wav` затёр бы камерный `клип.WAV`. Если имя всё-таки занято файлом другого формата, скрипт остановится на этом клипе.
- **Клипы без звука пропускаются.** Это slow-mo и таймлапсы Pocket 3. У slow-mo рядом лежит `.AAC`, но он идёт в реальном времени, а видео замедлено в 4 раза, поэтому таймкоды не совпали бы. Такой файл скрипт не использует.
- **Скрытые папки** (`.Trashes` и т. п.) не обходятся.
- **txt и srt собираются из JSON** (whisper-cli пишет только JSON), в том же формате, что у whisper-cli, — уже с заменами и нарезкой на субтитры.
- **Длинные сегменты режутся на субтитры.** Whisper иногда выдаёт сегмент на 20–50 секунд. Сегмент длиннее 7 с или 90 знаков режется по таймкодам слов: по концам предложений (короткие соседние предложения остаются вместе), а если предложение длинное — по запятой или слову ближе к середине, без огрызков короче 20 знаков. Паузы, которые Whisper приклеивает к словам, срезаются по участкам речи VAD. JSON не меняется: в нём сегменты Whisper как есть.
- **Перезапуск безопасен.** Уже расшифрованные клипы пропускаются. Прерванный прогон (Ctrl-C) просто запускается снова.
- **Служебные файлы `._*`**, которые macOS создаёт на exFAT, игнорируются.

### Замены

Слова, которые Whisper стабильно пишет неправильно (фамилии, названия, команды), исправляются списком замен — файлом `замены.txt`:

```
# комментарий
Потылицин -> Потылицын
esbook | ESBook | s-book -> es-book
git pool -> git pull
```

- Заменяются только целые слова. Если вариант написан с маленькой буквы, он заменяется и в начале предложения: русское слово тогда пишется с большой («прямо» → «Прямо»), а замена со строчной латинской буквы — название или команда (`ant-lab`, `git pull`, `main.c`) — остаётся как есть.
- Общий список лежит рядом со скриптом. Список проекта кладётся в `video/` или `video/src` проекта: скрипт ищет `замены.txt` в папке клипа и во всех папках выше. При совпадении главнее тот список, что ближе к клипу.
- **Поправил список — просто запусти скрипт снова.** Whisper не запускается: txt и srt собираются заново из JSON, где исходный текст Whisper сохранён в поле `text_raw` (а `text` — уже с заменами). С `-n` видно, в скольких клипах пересоберутся txt/srt.
- Замена срабатывает и через место разреза субтитров («git, клон» → «git clone», даже если разрез пришёлся после запятой); два куска тогда склеиваются в один.
- Таймкоды токенов в JSON остаются от исходного распознавания: замены меняют текст сегментов, а не токены.

### Подсказка `-p`

Whisper воспринимает подсказку как текст, который звучал перед записью. Поэтому он перенимает из неё стиль (пунктуацию, заглавные буквы) и охотнее пишет слова, которые в ней видел. Без подсказки он иногда пишет без знаков препинания и путает имена («Пателицын»).

**Откуда брать.** Подсказку пишешь сам, на каждый проект. Это 2–3 фразы в твоей манере речи, в которых правильно написаны:
- имена людей в кадре;
- название проекта и места;
- термины, марки, микросхемы, программы: то, что Whisper не знает или пишет по-своему (ESP32, KiCad, PlatformIO).

Источники — тема ролика, методичка или слайды, если это урок.

```bash
-p "Привет, друзья! На связи Иван Потылицын. Сегодня собираем Спутник: плата на ESP32, разводка в KiCad."
```

**Удобный порядок.** Первый прогон — с базовой подсказкой (приветствие и имя). Потом Claude читает расшифровки, находит искажённые термины и составляет подсказку для проекта. Второй прогон с `-f` быстрый: звук уже извлечён.

**Правила:**
- **Чем короче, тем лучше.** На тестах подсказка-список терминов на ~400 знаков заметно испортила разбивку: сегменты стали в 6 раз длиннее (до 50 с), и пропали две короткие фразы. Хорошо работает приветствие с именем и 2–3 самых важных термина. Остальные термины надёжнее чинить списком замен.
- Не больше ~500 знаков. Whisper берёт из подсказки 223 токена (по-русски это примерно 550–600 знаков), а у длинной отбрасывает начало.
- Только слова, которые в ролике действительно звучат: на неразборчивой речи Whisper может подставить слово из подсказки.
- Подсказка действует на весь клип (`--carry-initial-prompt`). Без этого флага whisper.cpp помнит её только первые минуту-две, а дальше её вытесняет распознанный текст.

### Известные ограничения

- Таймкоды в JSON — по токенам whisper.cpp, с точностью до десятых секунды. Для резки по словам позже подключим WhisperX.
- whisper-cli 1.9.5 с VAD пишет в JSON таймкоды токенов без учёта вырезанной тишины (сегменты при этом верные). Скрипт исправляет их сам по границам речи из лога whisper. Если после обновления whisper.cpp скрипт сообщит «не удалось пересчитать таймкоды токенов», значит, формат лога изменился и пересчёт надо поправить.
- VAD может пропустить очень тихую или короткую реплику. Настройки оставлены по умолчанию: на тестах более мягкие давали повторы фраз.

## Установка

```bash
brew install ffmpeg whisper.cpp
mkdir -p ~/whisper-models

# Модель распознавания (~1,6 ГБ)
curl -L -o ~/whisper-models/ggml-large-v3-turbo.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin

# Модель фильтра речи VAD (Silero, ~1 МБ)
curl -L -o ~/whisper-models/ggml-silero-v6.2.0.bin \
  https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v6.2.0.bin
```

Ещё нужен `python3` (на маке есть вместе с Xcode Command Line Tools): им скрипт поправляет таймкоды в JSON. Другие пути к моделям можно задать переменными `WHISPER_MODEL` и `VAD_MODEL`.

Сеть нужна только для установки. Дальше всё работает офлайн: на M2 Pro минута речи распознаётся за несколько секунд (Metal).

## Раскладка исходников

```
src/<месяц.день>/<камера>/клип.MP4
```

Например, `src/10.11/DOP3/DJI_20261110103235_0151_D.MP4`. Скрипту передаётся `video/src` проекта (или любая папка внутри неё).
